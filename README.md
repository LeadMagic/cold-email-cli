# Cold Email CLI: Archived Email Automation Project

This archived TypeScript and Bun project contains command-line integrations for email campaign platforms, including Smartlead, Instantly, Apollo, and others. It is retained as historical source code.

**Status: archived and not actively maintained.** Installation instructions and platform integrations may no longer match current third-party APIs.
